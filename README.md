# Raf Matos — Website

Site institucional (montra + pedido de orçamento) da **Raf Matos** — remodelações e construção civil interior e exterior (pladur, tijoleira, pintura, telhados, canalização, eletricidade), em Vila Nova de Gaia.

- **Stack:** site estático (HTML/CSS/JS), sem framework, **sem backoffice**. Alojado em **GitHub Pages**.
- **Contactos:** Pedro Matos — 937 605 547.

## Desenvolvimento local
```bash
python3 _source/dev-server.py    # http://localhost:8100
```

## Estrutura
- `index.html` — página principal
- `assets/` — css, js, imagens, fontes (self-hosted)
- `legal/` — privacidade, termos, cookies
- `_source/` — fotos originais (não publicado)

> Site sem venda online. Pedidos por WhatsApp/formulário.
